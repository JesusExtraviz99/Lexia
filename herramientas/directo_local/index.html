Ventana de hasta 4 s; actualización solicitada cada 0,125 s.

La última palabra reconocida queda subrayada de forma discreta; el fondo amarillo señala la siguiente palabra o el bloque pendiente. Las dos palabras avanzan una posición al reconocer cada palabra, sin esperar a completar una pareja fija. Esta guía visual no afirma que la siguiente palabra ya se haya leído y no avanza con un temporizador. La latencia del reconocimiento todavía puede hacer que llegue tarde.

Si el motor tarda más que el intervalo elegido, la frecuencia real será menor. Se procesa la ventana más reciente sin acumular una cola. Esta prueba usa el mismo alineador textual original para todos los modelos.

El audio del micrófono se procesa únicamente en este ordenador. Los registros de texto y tiempos se guardan localmente. El servidor no guarda WAV; la descarga opcional se prepara en el navegador. Esta prueba aún no mide el funcionamiento dentro de Android.
